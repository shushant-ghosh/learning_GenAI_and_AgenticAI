# Rock, Paper, Scissors Game

## Basics of the Game
Rock, Paper, Scissors is a simple hand game usually played between two people. The game has three possible moves:
- **Rock** beats **Scissors**
- **Scissors** beats **Paper**
- **Paper** beats **Rock**

Each player simultaneously forms one of the three shapes with their hand. The winner is determined based on the rules above.

## Instructions to Add, Stage, Commit, and Push Code
1. **Add** your changes to the staging area:
   ```bash
   git add .
   ```

2. **Stage** your changes (already done with the `git add` command above).

3. **Commit** your changes with a descriptive message:
   ```bash
   git commit -m "Your commit message here"
   ```

4. **Push** your changes to the current git branch:
   ```bash
   git push
   ```

Follow these steps to keep your code up to date with the remote repository.
